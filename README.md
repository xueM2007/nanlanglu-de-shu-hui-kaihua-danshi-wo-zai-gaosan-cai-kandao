# 南朗路的树会开花，但是我在高三才看到

高中毕业后，有人创建了腾讯共享文档，让大家写下自己的故事。这个仓库用来保存这些文字和每次归档的版本，让回忆有一份独立的备份。

## 目前状态

- 仓库已建立，初始设置为私有。
- 尚未导入故事正文，等待提供腾讯文档链接或导出的文件。
- 尚未配置自动同步。腾讯文档里的编辑不会自动出现在本仓库中。
- 本仓库只能保留实际归档的版本；首次备份前的旧版本，需要从腾讯文档的历史记录另行导出（若可访问）。

## 文件放在哪里

- [stories/](stories/)：适合直接阅读、比较修改的文字版本。
- [originals/](originals/)：腾讯文档导出的原始文件，按归档时间分别保存。

## 怎样保存新版本

1. 从腾讯文档导出最新文件，尽量保留 Word 原文件，并额外保存 PDF 以便保留排版。
2. 在 originals 下新建按北京时间命名的文件夹，例如 `2026-10-23_203000`，上传原始导出文件。
3. 如需方便查看文字变化，把正文整理为 stories 下的 Markdown（.md）文件。后续更新同一个文件即可。
4. 点击 GitHub 的 **Commit changes（提交更改）**，写清归档时间和来源，例如“归档 2026-10-23 晚间腾讯文档版本”。
5. 检查上传结果，打开文件确认内容完整。

原始文件每次用新的时间文件夹保存；文字文件更新同一路径。这样既能保留每份导出文件，也能通过文字文件的 **History（历史记录）** 查看变化。GitHub 的提交是保存版本，与向学校提交作业无关。

## 查看旧版本

打开文件后点击 **History**，选择以前的提交即可查看当时内容。恢复旧内容时，请把它作为一次新的更改保存，保留已有历史。

## 关于分享与长期保存

仓库目前为私有，访问需要仓库所有者授权。腾讯文档的分享权限与 GitHub 的权限分别管理。公开仓库或分享他人故事前，应先确认作者同意，并处理不适合公开的个人信息。

定期在仓库的 **Code → Download ZIP** 下载当前文件，另存到电脑或其他存储位置；ZIP 只包含当时的文件，不包含完整提交历史。如需备份完整历史，可使用 Git 克隆仓库，并定期更新副本。
